# rd-golden-threshold-core

Verification code for the manuscript *Spectral classification of linearized reaction–diffusion systems with an
adaptive golden-ratio threshold* (Hazime Sendo, Independent Researcher).

The code reproduces every numerical statement of Section 6 of the manuscript (Tables 1–4) and regenerates
Figures 1–4. No external data are used: everything is generated by the scripts from the parameters in
`data/parameters.json` (Table 1 of the paper).

## Folder structure

| folder | content |
|---|---|
| `src/` | model and lattice utilities: `reduced_rd.py` (three-component block lower-triangular system, example (4)), `lattice.py` (lattice Laplacian eigenvalues, Gauss-circle count N2) |
| `data/` | `parameters.json`: the parameters of Table 1 (no external datasets) |
| `scripts/` | `verify_all.py` (all checks, pass/fail), `verify_reduced.py`, `verify_theorems.py`, `verify_ratio.py` (detailed printouts), `make_figures.py`, `check_parameters.py`, `run_all.sh` |
| `results/` | `logs/` (output of one complete run, with the software versions) and `figures/` (Figures 1–4, pdf and png) |

## Requirements

Python 3 with the packages in `requirements.txt` (numpy, scipy; matplotlib only for the figures). Tested: Python 3.13 (numpy 2.5.3, scipy 1.18.1, matplotlib 3.11.2) and, in an independent run, Python 3.11 (numpy 2.4.4, scipy 1.17.1); other versions were not tested.

    pip install -r requirements.txt

The run recorded in `results/logs/` used the versions listed in `results/logs/environment.txt`.

## How to run

    python3 scripts/verify_all.py            # every numerical statement of Section 6; exit code 1 if any check fails
    python3 scripts/verify_all.py --quick    # same without the 2D lattice PDE runs (Section 6.4)
    python3 scripts/make_figures.py          # Figures 1-4 -> results/figures/
    bash scripts/run_all.sh                  # everything, logs -> results/logs/

`verify_all.py` is self-contained (needs only numpy and scipy). The other scripts import `src/`.
A full run takes seconds to about a minute, depending on the machine.

## What the checks do and do not show

* The expected values (656, 68, 0.2901, 5.894, ...) belong to the parameters of Table 1; if the parameters are
  changed, the expected values must be changed too (`scripts/check_parameters.py` checks that the code and
  `data/parameters.json` agree).
* Several checks compare two quantities computed from the same parameters (for example the lattice-count formula
  with a direct count of eigenvalues). They are consistency checks of the implementation; they do not replace the
  proofs in the paper.
* The equality case lambda = R (blocks v and w at k = 0, where g = h = R) is decided with the tolerance 1e-9.
* The closure-realization residual (about 2.5e-10 in the paper) is a central difference of an RK45 dense output with
  step 1e-6; the check only requires it to be below 1e-8, and the value in the paper is a reference figure.
* Figures are generated with matplotlib; they may differ from the published ones in fonts, not in content.

## Reproducibility log

`results/logs/` holds the output of `scripts/run_all.sh` on the date given in `environment.txt`.
Logs from another machine will agree up to floating-point differences in the last printed digits.
